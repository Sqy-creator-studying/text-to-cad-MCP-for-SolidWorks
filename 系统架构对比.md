# Text-to-CAD 系统架构对比

## 📊 你现在有两个独立的系统

### 系统1️⃣: Text-to-CAD 网站 (原有系统)

```
┌─────────────────────────────────────────────────────────┐
│                   用户打开网站                            │
│              http://localhost:xxxx                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│            在网页上输入自然语言                           │
│     "创建一个直径50mm高度100mm的圆柱体"                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│          cad_module/server.py (Flask后端)               │
│          cad_module/api/natural_cad.py                  │
│          AI解析 → 选择模板 → 生成参数                    │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│          cad_module/generators/ (代码生成CAD)            │
│          生成 STEP/STL/GLB 文件                          │
│          ❌ 不需要 CATIA/SolidWorks                       │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│          viewer/ (React前端 + Three.js)                  │
│          在浏览器中显示3D模型                             │
└─────────────────────────────────────────────────────────┘
```

**特点:**
- ✅ 完全基于Web
- ✅ 不需要安装CAD软件
- ✅ 使用Python代码直接生成CAD文件
- ✅ 浏览器中查看3D模型
- ❌ 不能在专业CAD软件中编辑

---

### 系统2️⃣: CATIA MCP工具 (新配置的)

```
┌─────────────────────────────────────────────────────────┐
│              用户在Claude Code对话框输入                  │
│     "在CATIA中创建一个直径50mm高度100mm的圆柱体"          │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│            Claude识别需要调用CATIA MCP工具                │
│            cad_module/mcp_servers/catia_mcp.py          │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│            通过COM连接控制CATIA软件                       │
│            ✅ 需要 CATIA 正在运行                         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│            在CATIA中直接创建零件                          │
│            可以在CATIA中继续编辑                          │
└─────────────────────────────────────────────────────────┘
```

**特点:**
- ✅ 直接在专业CAD软件中建模
- ✅ 可以在CATIA中继续编辑
- ✅ 使用CATIA的全部功能
- ❌ 需要安装CATIA
- ❌ 不是通过网站，而是通过Claude对话

---

## 🔄 可能的集成方案

### 方案A: 网站调用CATIA (如果你想要)

```
用户在网站输入
    ↓
后端API判断
    ↓
如果选择"CATIA模式" → 调用 catia_mcp.py → CATIA创建
如果选择"在线模式" → 代码生成 → Web查看器显示
```

### 方案B: 保持独立 (目前状态)

- **网站**: 快速原型，在线查看
- **CATIA MCP**: 专业建模，需要继续编辑的场景
